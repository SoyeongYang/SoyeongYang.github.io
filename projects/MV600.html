A pipeline of XR-based Moving Trajectory Editing System for Choreography Production

Course: [MV600] Augmented Reality Project (KAIST)
Role: Project Leader & Developer
Stack: C++, Unity, VR Interaction, Rendering Algorithm
📄 Paper

Abstract

Digital twins (DT) and Extended reality (XR) are widely explored fields of study in many applications. However, the implemented application or defined framework for choreography editing is not studied, in spite of its possible increase in utility. In this work, we propose a novel approach to utilize the DT+XR environment for choreography production. Our method will contain a user interface, trajectory editing, and server in a single framework. Furthermore, studies on each technological component will be contained for detailed implementation. Unlike existing trajectory production applications, it is expected to be useful to choreographers as it can be observed from various perspectives since this system utilizes 3D space which makes a significant contribution to the choreography field by intuitively and easily creating movement lines. The movement data of each dancer saved from the user also can be augmented in various other real-world stages later to simulate the dancers’ movements in advance.
